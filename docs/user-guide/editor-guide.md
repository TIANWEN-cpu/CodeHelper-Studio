# 编辑器指南

CodeHelper 内置 CodeMirror 6 编辑器（@uiw/react-codemirror），提供专业的代码编辑体验。

## 概览

编辑器模块由以下组件构成：

- **CodeEditor** - 核心编辑器组件，基于 CodeMirror 6
- **EditorTabs** - 多标签页管理
- **Console** - 内置控制台面板，查看代码运行输出
- **TerminalPanel** - 终端面板集成

## 编辑器功能

### 语法高亮

CodeMirror 支持主流编程语言的语法高亮，包括但不限于：

| 语言       | 文件扩展名     |
| ---------- | -------------- |
| Python     | `.py`          |
| JavaScript | `.js`、`.jsx`  |
| TypeScript | `.ts`、`.tsx`  |
| C          | `.c`、`.h`     |
| C++        | `.cpp`、`.hpp` |
| Java       | `.java`        |
| C#         | `.cs`          |
| SQL        | `.sql`         |
| Markdown   | `.md`          |
| JSON       | `.json`        |
| HTML       | `.html`        |
| CSS        | `.css`         |

### 智能代码补全

- 基于语言上下文的智能提示
- 代码片段自动展开
- 参数信息提示
- 悬停信息展示

### 代码编辑特性

- **代码折叠** - 折叠/展开代码块（点击行号左侧的折叠箭头）
- **括号匹配** - 自动高亮匹配的括号
- **自动缩进** - 根据语言规则自动调整缩进
- **多光标编辑** - `Alt+Click` 添加多个光标同时编辑
- **块注释切换** - `Ctrl+/` 切换注释
- **代码格式化** - 自动调整代码格式
- **智能粘贴** - 粘贴代码时自动调整缩进

## 多标签页管理

### 标签页操作

| 操作               | 方式                   |
| ------------------ | ---------------------- |
| 新建标签页         | 通过题目详情或手动创建 |
| 切换标签页         | 点击标签页标题         |
| 关闭标签页         | 点击标签页右侧关闭按钮 |
| 重新打开关闭的标签 | 点击标签栏中的恢复按钮 |

### 标签页特性

- 每个标签页独立保存代码内容
- 标签页标题显示当前编辑的文件/题目名称
- 工作区底部状态栏会显示当前内容的保存状态
- 支持同时打开多个标签页并行编辑
- 工作区最多同时打开 50 个标签页；关闭的标签会保留在最近关闭列表中，重启应用后仍可点击标签栏的恢复按钮重新打开
- 编辑内容和切换语言会立即写入崩溃恢复日志；完整工作区快照保存失败时，内存内容和恢复日志都会保留，并在状态栏显示错误
- Electron 中的标签内容、语言、文件名、顺序、光标和滚动位置会同步到 SQLite；IPC 或数据库不可用时状态栏会明确显示“工作区仅本地保存”，不会把降级路径标成完整同步
- 题目 starter code 会等待 SQLite 工作区恢复完成，并且只写入真正为空的文档；欢迎示例、远端新版本或用户已有代码不会被首次加载和切换语言覆盖
- 关闭有待保存、失败或冲突状态的标签时会先显示针对该标签的确认。SQLite 重试仍失败时，标签保持打开；用户可以再明确选择“仅在本地关闭”，内容会进入最近关闭列表且状态继续标为降级
- 多窗口同时编辑同一标签时使用 revision/CAS 防止静默覆盖。当前多窗口仍共享 active tab、光标和滚动位置，不提供实时协同合并；发生冲突时，工作区会显示目标文件、待处理数量和三项文字操作：采用数据库版本、保留本地写入新版本、另存本地副本
- 损坏或不支持版本的本地快照会完整备份到 `.corrupt.*` 键；若只能打开默认工作区或部分恢复，顶部提示和状态栏会明确显示恢复降级，不会显示“已保存”
- 关闭应用窗口时会等待编辑器和当前练习草稿完成有界保存；保存失败或超时时窗口不会静默退出，而会明确提供“返回应用”和“仍然关闭”选择
- 普通文件、题目和练习共用统一多标签拓扑（`kind: file | problem | exercise`）；标签栏会显示类型图标与“文件 / 题目 / 练习”标签
- 练习标签只保存拓扑与视图状态（文件名、语言、光标、滚动、排序）；**练习代码本身不以 `editor_tabs.content` 为权威**，而是走独立练习草稿 SQLite / recovery 流程。状态栏在练习模式下显示草稿同步/冲突/失败，不会伪装成完整工作区已保存

### 练习草稿恢复

- 打开练习时会创建或激活对应的 `exercise` 标签；代码与所选语言作为练习草稿自动保存，并在重新进入应用时恢复
- 练习标签可关闭、切换，并进入最近关闭列表；重启后可从恢复区与统一工作区快照恢复拓扑
- 保存使用数据库 revision 防止旧窗口或迟到请求覆盖更新内容
- 编辑后立即关闭窗口时，本地恢复区会保留尚未完成 IPC 写入的最新快照
- 检测到版本冲突时，状态栏会显示冲突，并提供“重新加载已保存草稿”和“保留本地草稿”两个操作
- 恢复区达到 20 条或 1,000,000 字符总量时不会删除旧草稿来腾空间；新写入会显示容量错误。损坏的恢复 JSON 会先完整备份并停止覆盖
- 从旧版快照恢复时，若练习标签仍内嵌代码，会把代码备份为本地恢复文件标签，并清空练习标签 content，避免草稿双写

## 编辑器设置

在 **设置** 模块中可以自定义编辑器行为：

| 设置项   | 说明                  | 默认值       |
| -------- | --------------------- | ------------ |
| 字体大小 | 编辑器文字大小        | 14px         |
| Tab 宽度 | 每个 Tab 占用的空格数 | 4            |
| 主题     | 编辑器配色方案        | 跟随应用主题 |

## 控制台面板 (Console)

控制台面板位于编辑器下方，用于显示代码运行结果。

### 功能

- **标准输出 (stdout)** - 以绿色显示程序的正常输出
- **标准错误 (stderr)** - 以红色显示错误信息
- **退出码** - 显示程序的退出状态码
- **执行时间** - 显示代码运行耗时
- **编译阶段指示** - 对于 C/C++/C# 等编译型语言，区分编译错误和运行时错误

### 运行代码

1. 在编辑器中编写代码
2. 点击运行按钮或使用快捷键执行
3. 查看控制台面板中的输出结果

### 资源限制

代码运行器内置安全保护机制：

| 限制项     | 值     | 说明               |
| ---------- | ------ | ------------------ |
| 执行超时   | 10 秒  | 超时后自动终止进程 |
| 输出大小   | 1 MB   | 超出限制自动截断   |
| 最大并发数 | 5 个   | 同时运行的进程上限 |
| 代码长度   | 100 KB | 单次提交代码上限   |

## 提交代码到题库

在编辑器中编写的代码可以直接提交到题库系统进行自动判题：

1. 确保当前标签页关联了题目
2. 在控制台面板或题目详情中选择编程语言
3. 点击 **提交** 按钮
4. 系统自动运行所有测试用例并返回结果
5. 判题结果包括：通过 (Accepted)、答案错误、编译错误、运行时错误、超时
